# AXA Motor Claim Management

Mobile-first (PWA) application replacing AXA Middle East's email-based motor claim photo workflow, pushing captured photos and documents directly into NEXT3 under the correct visa number.

Four profiles: **Expert**, **Garage**, **Claim Officer**, **Broker**.

> **Status: pre-kickoff.** BRD analysed, scope proposed, no code written, no client answers received.
