Deactivating

The one destructive action on this screen, and the only one that asks.

Deactivate PLACEHOLDER Expert One? They will no longer be able to sign in.
Cancel Deactivate

There is no reactivate and no delete. An inactive profile stays inactive and keeps its history; if the person comes back, they are created again. Work already in flight is untouched — a claim they were assigned stays assigned.

Inviting

Creating a profile sends the invitation; Re-send issues a fresh one.

Invite sent.

Only offered while the profile is still invited. Once somebody has signed in, the button disappears — there is nothing to re-send.

Invitations last seven days, which is why re-sending exists at all.

Three states, three row treatments

active signs in, gets work invited created, never signed in inactive cannot sign in, kept for the record

The inactive row is greyed as well as chipped: an admin scanning a long list should see at a glance who is switched off, without reading a column.

The other three profile types use this same table with their own columns — garages carry contact, address and opening hours; claim officers a NEXT3 user; brokers an IRIS code.
