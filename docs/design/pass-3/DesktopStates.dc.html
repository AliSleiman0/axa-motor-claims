AlertBanner · desktop

NEXT3 is unreachable, so claims cannot be searched right now. Try again shortly.
NEXT3 does not have a claim under that visa number. Create the visa in NEXT3, then search again.
This declaration has already been decided — reopen it to see where it is now.
Could not load the inbox (503).
Enter a plate number or a visa number to search.

Amber is NEXT3 being unavailable — wait and it may fix itself. Red is a refusal — waiting changes nothing, so every red banner names the next move.

The last one is refused on the screen before a request is made, and refused again by the server: a search with neither term would otherwise ask NEXT3 for every claim it has.

Desktop controls are 36 px and their labels 14 px — denser than the phone's 48 px, because these people are at a desk with a mouse. Everything else about them is identical.

Nothing new was invented for the desktop: the same six tokens, the same two banner shapes, the same chip anatomy. The only additions are the broker's seven states, the profile statuses and the outbox operation names — all of them values the system already has.
