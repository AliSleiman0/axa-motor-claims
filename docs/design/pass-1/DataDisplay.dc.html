Every value on this artboard is deliberately fake. A missing value is an em dash — never a blank cell, never “N/A”, because on a cold NEXT3 cache the difference between “we do not have it yet” and “nobody filled it in” is the difference between waiting and phoning someone.

A photograph gets a real thumbnail (drawn here as a placeholder block); a PDF or an audio file gets a named link and nothing else. Rendering a PDF into an image element is how the build once showed an expert a broken-image icon on the one screen whose job is that a person looked at the file.
