Five buckets, five distinct controls

the fix this pass owes the build

Today every capture control on the expert screen reads Take a photo and every file control reads Choose a file — five and three identical names in one page, which is unusable with a screen reader and ambiguous with a glove on. The qualifier line under each label is the whole fix: it is also the control's accessible name.
