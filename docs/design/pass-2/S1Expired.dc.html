One screen for three causes — expired, already used, and never valid — because the server answers all three identically on purpose. Naming which one it was would let anyone test invitations to see which exist.
The message says may rather than picking one, and the way out is a person rather than a retry: an admin can re-issue an invitation from the profile screen while the account is still in the invited state.
Sign in stays offered because an already-used invitation usually means the account is active — the person is not stuck, they just need the other door.
