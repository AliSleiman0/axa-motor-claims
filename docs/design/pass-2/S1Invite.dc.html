Contract note. Today the invitation SMS carries the raw token as text — “Your registration invite token is …” — with no link to tap, which is why the paste path above exists at all. If AXA wants the tidy version, the SMS needs to carry a URL; that is a one-line change to the message and a route on the web app.
The screen cannot show which number the code goes to: the invitation is the only thing the browser holds, and the API deliberately returns nothing about the person behind it. Showing a masked number would need a new endpoint and a decision about what it reveals.
Nothing else is collected here — no name, no password, no photograph. The profile already exists; this only proves the phone is yours.
